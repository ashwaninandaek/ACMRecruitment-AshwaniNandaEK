#Lemonade Change
1. Initialize variables, c_5 and c_10 to 0.
2. Using for loop iterate through bills.
3. Check if 5 or 10 and add to c_5 or c_10.
4. If 10, check if count of 5(c_5) greater than or equal to 1. If so subtract 1 from c_5 or else return 'False'.
5. If 20, check if c_5 and c_10 greater than or equal to 1. If so subtract one from each. If not check if c_5 greater than or equal to 3. If so subtract 3 from c_5 or else return "False".
6. Repeat the steps till loop iterate through the whole list.
7. If the loop doesn't break in-between return 'True'.
